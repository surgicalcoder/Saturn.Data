## Non-negotiable rules

1. **Do not change the existing public generated API.** `To_{View}()`, `Generate`, `UpdateFrom`, `Selector`, `Create`, `UpdateParent`, and view class names must keep their signatures. Behavior may be hardened.
2. **Do not add comments to generated `.cs` or handwritten `.cs` files** (house style). The only allowed header is `// <auto-generated/>`.
3. Follow house style: file-scoped namespaces, no underscore-prefixed private fields, lowerCamelCase private fields, cuddled Egyptian braces, one statement per line, modern C#.
4. Analyzers/generators target `netstandard2.0`; do not raise the target framework.
5. **Intra-repo dependencies use `ProjectReference`, never NuGet.** Replace the `Saturn.Generator.Entities.Resources` → `GoLive.Saturn.Data.Entities` NuGet pin (`3.4.28`) with a project reference to the in-repo `7.0.0` project. Third-party packages (`Microsoft.CodeAnalysis.CSharp`, `ObservableCollections`, `xunit`) stay NuGet.
6. Every phase ships with tests in `Saturn.Generator.Entities.Tests` (new project; see Phase A) plus the playground build.
7. **Tracking is opt-in and separable.** `GoLive.Saturn.Data.Entities` must not reference `GoLive.Saturn.Data.ChangeTracking`. The base `Entity` gets only type-free hooks; the generator emits tracking code only into opted-in classes.
8. **DTOs and entities both track** (decision 6); DTO identity defaults to `_shortId` (decision 4); refs are id-by-default with an auto-expand option (decision 5).

## Terminology

- **Entity**: a `partial` class deriving `GoLive.Saturn.Data.Entities.Entity`.
- **Limited view**: generated `{Entity}_{ViewName}` class driven by `[AddToLimitedView]`; authorization projection.
- **DTO**: generated `{Entity}Dto` class driven by `[GenerateDto]`; general-purpose transport object.
- **Change set**: `EntityChangeSet` (non-generic) describing field-level mutations.
- **Update document**: MongoDB-style `{ "$set": {...}, "$unset": {...}, "$inc": {...} }` consumed by `IRepository.Patch`.
