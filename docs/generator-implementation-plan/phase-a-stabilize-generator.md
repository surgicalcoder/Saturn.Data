# Phase A — Stabilize the Existing Generator

**Goal:** Fix latent correctness bugs in the current generator and add a generator test harness, without changing the generated public API.

**Prerequisite:** Read `README.md` and `../generator-dto-mapping-change-tracking-assessment.md` §4.2, §5.2, §15.

**Exit criteria:**
- Playground builds; its generated output contains no null-dereference path for unpopulated refs.
- `Saturn.Generator.Entities.Tests` exists and its snapshot tests pass.
- No existing generated method signature changed.

## Task A.1 — Null-safe ref mapping (assessment D2, critical)

**Problem:** Generated view classes emit:

```csharp
public static implicit operator MainItem_View1(Ref<MainItem> source)
{
    var retr = new MainItem_View1();
    retr.UpdateFrom(source?.Item);
    return retr;
}

public void UpdateFrom(MainItem source)
{
    OnUpdateFromStart(source);
    this.Name = source.Name;
    this.Id = source._shortId;
    OnUpdateFromEnd(source);
}
```

When `Ref<MainItem>.Item` is `null` (a normal, unpopulated reference), `UpdateFrom(null)` dereferences `source` and throws `NullReferenceException`.

**Fix:** In `SourceCodeGenerator.cs`, in the method that emits `UpdateFrom({Entity} source)` for view classes, emit a null guard as the first statement:

```csharp
public void UpdateFrom(MainItem source)
{
    if (source is null)
    {
        return;
    }

    OnUpdateFromStart(source);
    ...
}
```

And in the method that emits the scalar member assignment inside `UpdateFrom`, when the source member is a reference type, emit a null-safe conditional for nested view/ref mappings only (scalars can stay direct). For `Ref<T>`-to-view members the desired shape is:

```csharp
this.Fifth = source.Fifth?.Item is null ? null : (FifthItem_PublicView)source.Fifth;
```

If the emitter cannot express the null-conditional cleanly, emit:

```csharp
if (source.Fifth?.Item is not null)
{
    this.Fifth = source.Fifth;
}
```

**Verify:** In the playground, load a `FourthItem` whose `Fifth` ref has no `Item`, call `FourthItem_View1.Generate(item)`, and confirm it returns without throwing. Add this as a test in Task A.6.

## Task A.2 — Fix the string `_runAfterSet` flag (assessment C14)

**Problem:** `Scanner.cs` around lines 408-411 sets `HasRunAfterSetMethodIsRefItem = true` when the `_runAfterSet` parameter is `string`, so the wrong emission branch runs and the hook is never invoked.

**Fix:** In that branch, set the string flag instead:

```csharp
if (parameterType.SpecialType == SpecialType.System_String)
{
    memberToGenerate.HasRunAfterSetMethodIsString = true;
}
else
{
    memberToGenerate.HasRunAfterSetMethodIsRefItem = true;
}
```

Then verify `SourceCodeGenerator` emits a call to the string hook inside the generated setter (locate the branch that currently only handles `HasRunAfterSetMethodSimple` and `HasRunAfterSetMethodIsRefItem`). The generated setter shape must be:

```csharp
public string Test3
{
    get => test3;
    set
    {
        if (SetField(ref this.test3, value))
        {
            Test3_runAfterSet(value);
        }
    }
}
```

Add a playground entity with a `string`-parameter `_runAfterSet` and assert the hook fires.

## Task A.3 — Copy property attributes to views (assessment D4)

**Problem:** `Scanner.cs` builds `outputAttributes` only for `member is not IPropertySymbol` (around lines 419-445), so property attributes such as `[Required]`, `[StringLength]`, `[Range]`, `[JsonIgnore]`, `[JsonPropertyName]` are lost on generated views/DTOs.

**Fix:** Remove the `member is not IPropertySymbol` guard so both fields and properties contribute attributes. Keep filtering by namespace: never copy attributes from `GoLive.Saturn.Generator.Entities.Resources`, `GoLive.Saturn.Data.Entities`, or `System.Runtime.CompilerServices`; only copy attributes whose namespace starts with `System.ComponentModel.DataAnnotations`, `System.Text.Json.Serialization`, or the user's own namespaces.

**Verify:** Add a playground entity with `[Required] public partial string Name { get; set; }` and confirm the generated view property carries `[Required]`.

## Task A.4 — Preserve nullability (assessment D5)

**Problem:** Generated view properties are non-nullable even when the entity member is `string?`.

**Fix:** Add a nullable flag to `MemberToGenerate` (e.g., `IsNullable`) computed in `Scanner.ConvertToMembers` from `ITypeSymbol.NullableAnnotation == NullableAnnotation.Annotated`. In `SourceCodeGenerator`, when emitting a reference-typed view property, append `?` when the flag is set (and `#nullable enable` is not disabled in the output). Emit the standard header at the top of every generated file:

```csharp
// <auto-generated/>
#nullable enable
```

Do not disable nullable reference types.

**Verify:** A `string?` entity member produces `public string? X { get; set; }` in the view.

Create `GeneratorTestHarness.cs`:

```csharp
using System.Collections.Immutable;
using GoLive.Saturn.Data.Entities;
using GoLive.Saturn.Generator.Entities;
using GoLive.Saturn.Generator.Entities.Resources;
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.CSharp;

namespace Saturn.Generator.Entities.Tests;

public static class GeneratorTestHarness
{
    public static Compilation CreateCompilation(string source)
    {
        var paths = ((string)AppContext.GetData("TRUSTED_PLATFORM_ASSEMBLIES")!).Split(Path.PathSeparator);
        var references = paths.Select(path => (MetadataReference)MetadataReference.CreateFromFile(path)).ToList();
        references.Add(MetadataReference.CreateFromFile(typeof(Entity).Assembly.Location));
        references.Add(MetadataReference.CreateFromFile(typeof(AddToLimitedViewAttribute).Assembly.Location));

        return CSharpCompilation.Create(
            "GeneratorTests",
            new[] { CSharpSyntaxTree.ParseText(source) },
            references,
            new CSharpCompilationOptions(OutputKind.DynamicallyLinkedLibrary));
    }

    public static ImmutableArray<(string HintName, string Text)> Run(string source)
    {
        var compilation = CreateCompilation(source);
        var driver = CSharpGeneratorDriver.Create(new SaturnGenerator().AsSourceGenerator());
        var updated = driver.RunGeneratorsAndUpdateCompilation(compilation, out var output, out var diagnostics);

        var errors = diagnostics.Where(diagnostic => diagnostic.Severity == DiagnosticSeverity.Error).ToList();
        Assert.Empty(errors);

        var runResult = updated.GetRunResult();
        return runResult.Results.SelectMany(result => result.GeneratedSources).Select(generated => (generated.HintName, generated.SourceText.ToString())).ToImmutableArray();
    }

    public static string GeneratedFor(string source, string hintNameFragment)
        => Run(source).Single(generated => generated.HintName.Contains(hintNameFragment)).Text;
}
```

> If `SaturnGenerator` implements `IIncrementalGenerator`, `AsSourceGenerator()` is correct. If it implements `ISourceGenerator`, pass `new SaturnGenerator()` directly.

Create `StabilizationTests.cs`:

```csharp
namespace Saturn.Generator.Entities.Tests;

public class StabilizationTests
{
    private const string Source = """
        using GoLive.Saturn.Data.Entities;
        using GoLive.Saturn.Generator.Entities.Resources;

        namespace Sample;

        [AddParentItemToLimitedView("*", "_shortId", ChildField = "Id", InheritFromIUniquelyIdentifiable = true)]
        public partial class Parent : Entity
        {
            [AddToLimitedView("View1")]
            private string name;
        }

        public partial class Child : Entity
        {
            [AddToLimitedView("View1", LimitedViewType = typeof(Parent_View1))]
            private Ref<Parent> parent;
        }
        """;

    [Fact]
    public void View_Emits_Auto_Generated_Header()
    {
        var generated = GeneratorTestHarness.GeneratedFor(Source, "Child.g.cs");
        Assert.StartsWith("// <auto-generated/>", generated);
    }

    [Fact]
    public void UpdateFrom_Is_Null_Guarded()
    {
        var generated = GeneratorTestHarness.GeneratedFor(Source, "Child.g.cs");
        Assert.Contains("if (source is null)", generated);
    }

    [Fact]
    public void Ref_Implicit_Operator_Is_Null_Safe()
    {
        var generated = GeneratorTestHarness.GeneratedFor(Source, "Child.g.cs");
        Assert.Contains("source?.Item", generated);
        Assert.DoesNotContain("retr.UpdateFrom(source?.Item);\n        return retr;", generated);
    }
}
```

Replace the string assertions with golden-file comparison once output is stable (`Assert.Equal(File.ReadAllText("Golden/Child.g.cs"), generated)` with a `Goldens` folder).
